# Credit Risk Analysis

## Overview
This project analyses loan default risk using Python, SQL Server, machine learning, and Power BI.

## Objectives
- Explore borrower characteristics and loan default patterns.
- Clean and analyse data.
- Build and compare machine learning models.
- Evaluate model performance and decision thresholds.
- Present insights through a Power BI dashboard.

## Tools
- Python: pandas, scikit-learn
- SQL Server
- Power BI
- Jupyter Notebook

## Project contents
This project includes Python notebooks for data analysis and predictive modelling, SQL scripts for database analysis, and Power BI dashboard materials.

*Model results and findings should be verified against the final executed notebooks and dashboard.*
